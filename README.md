# Game Sandbox

Game Sandbox is a shared playground for game-playing AI, built for classes. Students write Python agents, test them locally, and submit them through GitHub. Everyone can watch the submitted agents, play with or against them, rate them, and compare them on per-environment leaderboards.

Choose the section that matches what you are doing:

| I want to... | Start here |
| --- | --- |
| Write and submit an agent | [Student guide](docs/students/index.md) |
| Develop Game Sandbox itself | [Contributor guide](docs/contributors/index.md) |
| Understand the product rules and architecture | [Specification](docs/specs/index.md) |

The documentation under [docs/](docs/index.md) is an MkDocs site. You can also read it on GitHub, starting from [docs/index.md](docs/index.md). The environment catalog is generated by the documentation site, so use your student template's README to identify your environment when browsing on GitHub.

The implementation plan and its per-stage status live under [plans/](plans/README.md).
