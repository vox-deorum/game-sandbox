# backend/

The Node and TypeScript service for HTTP APIs, storage, submissions, seasons, ratings, session orchestration, and the browser-to-container WebSocket relay.

```console
npm run dev
npm test
npm run test:integration
npm run build:image
```

See the [backend contributor guide](../docs/contributors/backend.md), [execution boundary](../docs/contributors/execution.md), and [implementation plan](../plans/README.md).
