# Stage 11: Semantic Contract

Status: not started.

## Goal

Agents read observations as self-describing objects of typed entities, and pick actions through helpers instead of hand-decoding a bit mask. A Hearts agent reads a hand of card objects `{"suit": 2, "rank": 12}` (rank as face value, ace high) and answers `return play(card)` instead of decoding bit 36 of a mask and computing an integer. The observation becomes an object-shaped composite Gymnasium space; the action stays a simple `Discrete(n)` chosen through a binary `action_mask`, wrapped by ergonomic helpers so the index never surfaces. Every environment stays a conformant PettingZoo AEC environment — the spaces are real `gymnasium.spaces`, `pettingzoo.test.api_test` keeps passing, and the mask stays the legality channel.

This establishes the platform convention for the next wave of environments: **object-shaped observations, a simple `Discrete` action space with a binary mask, and helpers that hide the index.** This is a deliberate choice over composite/tagged action spaces. Gymnasium's masked sampling (`Space.sample(mask)`) cannot constrain a composite `Dict`/`OneOf` action to an arbitrary legal set — a `Dict({suit,rank})` mask yields the suit×rank cross-product, and `OneOf` chooses its arm uniformly regardless of the mask — so a composite action would defeat `action_mask`, force a legality-eroding "total step", and break masking-aware tooling. Keeping the action a flat `Discrete` keeps the observation free to be richly typed while the environment stays fully idiomatic PettingZoo. The three existing environments (Hearts, Spades, Flappy Bird) move to the convention now, while the surface area is small.

## Scope

The observation contract. Observations keep the `{"observation": {...}, "action_mask": Box(n)}` wrapper (the mask must stay a top-level key for `api_test`'s masked-sampling path), but the inner state becomes object-shaped composite spaces. Cards are objects `{"suit": <0..3>, "rank": <2..14>}` — suit is `Discrete(4)` (the integer is on the wire; suit _names_ live in helpers) and rank is `Discrete(13, start=2)` as face value (J is 11, Q is 12, K is 13, A is 14), so rank compares numerically with no lookup table. A hand is a `Sequence(CARD)`; a trick is a play-ordered `Sequence` of `{"seat": <0..3>, "card": {...}}` records (a sparse seat-keyed dict is impossible — `Dict.contains` requires every key). Nullable scalars use the `Discrete(n+1)` "extra category" pattern (`led_suit` category 4 = none; an unbid Spades seat = 14). The Spades observation also gains `partner_seat` and the running `team_scores` projection the rules engine already computes, and Flappy Bird's opaque twelve-float vector becomes the same player-and-pipes object its overlay already carries. The exact field-by-field shapes live in the subplans.

The action contract stays simple. Actions remain a flat `Discrete(n)` (Hearts `Discrete(52)`, Spades `Discrete(66)` with a phase-aware mask, Flappy `Discrete(2)`), legality remains the binary `action_mask`, and `env.step` still takes an integer and still raises `IllegalMoveError` on an illegal one. What changes is only ergonomics: helpers `play(card)`, `bid(n)`, `flap()`/`idle()` build the index from an object, and `legal_cards(obs)`/`legal_bids(obs)` decode the mask into objects, so a student writing an agent reads object-shaped state and returns `play(card)` and never touches an index or a bit. Spades' `52 + k` bid encoding survives inside `bid(n)`, hidden.

Shared structures and publication. The card observation building blocks (`CARD`, `HAND`, `TRICK`, the int↔object codec) live once in a new dependency-light `environments/src/local_play/spaces.py`, synced to every template through `TEMPLATE_BASE_MODULES` (the channel that already ships `render_cards.py`), replacing the byte-for-byte `suit_of`/`rank_of` duplication across the two `rules.py`. The published contract is the live space objects themselves: no JSON-Schema artifact, no new `EnvironmentMeta` field, no change to `environments.json`. Students introspect `env.observation_space(agent)`, and the harness reads spaces from the live registry (it already does). The one harness change is that `default_action` becomes `default_action(env, slot_id)` and returns the real lowest-legal card index, so a timeout records the action actually played rather than a sentinel.

The clean break. The observation shape change is breaking for agents that read the old `MultiBinary`/`Box` fields, so the template dependency set bumps from version 1 to version 2: templates, helper modules, examples, built-in agents, student docs, and test fixtures are rewritten to the object-shaped observation and the helper-driven action, and `deps-v1` is documented as incompatible with checkouts past this stage. Rules engines stay int-based internally (they are pure and heavily tested); the int↔object codec lives in the shared `spaces.py` and is applied only at the `env.py` and `overlay.py` boundaries. Overlays go object-shaped too, because overlays are part of the recorded artifact, and both renderer stacks (Pixi and pygame) normalize card objects back to integers at their single overlay-read boundary so geometry, animation, and hit-test code stays int-keyed.

Out of scope: any new environment, any change to the AEC loop or the action encoding, chat, the LLM gateway, and replay compatibility for pre-stage recordings.

## Build order

Each step is its own subplan under [stage-11/](stage-11/), plus a cross-cutting [testing, CI, and docs](stage-11/8-testing-ci-and-docs.md) companion. The shared spaces module and the small harness change land first; the three environments convert one at a time, each leaving the repo green with `api_test` still passing; publication, renderers, and the template bump follow; docs close the stage.

1. **[Harness and shared spaces](stage-11/1-harness-and-shared-spaces.md).** The shared `local_play/spaces.py` (card/hand/trick spaces and codec) and the `default_action(env, slot_id)` signature. The boundary check (`action_space(slot).contains` plus `action_mask`) is unchanged. No environment converts yet.
2. **[Hearts semantic observation](stage-11/2-hearts-semantic-contract.md).** The object-shaped inner observation over the shared spaces, semantic overlay, the pygame path, and the helper read/write split. Action, mask, `step`, and `api_test` stay. Hands-on: a Hearts hand playable locally over the object-shaped observation. This is the api_test-passes spike that de-risks the composite observation space.
3. **[Spades semantic observation](stage-11/3-spades-semantic-contract.md).** The same conversion plus the new `partner_seat` and `team_scores` leaves, null bids as category 14, and the seat-keyed `last_trick` as a play-ordered `Sequence`. Action stays `Discrete(66)` + phase mask; `bid(n)` hides `52 + k`. Hands-on: a Spades hand playable locally, bid chips included.
4. **[Flappy Bird semantic observation](stage-11/4-flappy-bird-semantic-contract.md).** A flappy-specific AEC subclass that overrides its space accessors to return the object-shaped space (its inherited accessors currently return the wrapped game's float vector) and whose observation is the player-and-pipes object read from the same internals as the overlay. `Discrete(2)` action unchanged. Hands-on: Flappy Bird playable locally over the object-shaped observation.
5. **[Publication and generation](stage-11/5-publication-and-generation.md).** The shared `spaces.py` joins `TEMPLATE_BASE_MODULES`, the generated template surface exports `default_action`, and every generated artifact is regenerated. No schema flows into `environments.json`; the spaces are the contract. Hands-on: `npm run generate` idempotent, `spaces.py` in every template.
6. **[Browser renderers and recorded fixtures](stage-11/6-browser-renderers-and-fixtures.md).** The Pixi renderers read object-shaped overlays and normalize cards to ints at one boundary; sent actions stay integer indices. The recorded fixtures are regenerated, including a new Flappy Bird fixture generator. Hands-on: watch, play, and replay all three games in the browser.
7. **[Template v2, examples, and builtins](stage-11/7-template-v2-examples-and-builtins.md).** The helper modules rewritten over the object-shaped observation (read/write split), every example and built-in agent migrated on their observation reads, and the dependency-set bump to version 2. Hands-on: a composed template plays end to end.
8. **[Testing, CI, and docs](stage-11/8-testing-ci-and-docs.md).** The Docker-gated integration tests and browser journeys on the new observation, the student docs rewrite, the convention added to the contributor environment-authoring guide, and the Stage 7 and 8 passages that described the old observation shape as current. Per-step tests live in each subplan.

## Done when

An agent written against any of the three environments reads object-shaped observations (a hand of `{suit, rank}` objects, a trick of `{seat, card}` records) and returns an action through a helper (`return play(card)`), never touching a bit or an index. The environment stays a conformant PettingZoo AEC environment — `test_passes_pettingzoo_api_test` passes for all three, `observation_space.contains` holds across a full episode, the `action_mask` still gates legality, and `env.step` still raises on an illegal index. All three games are watchable, playable, and replayable in the browser and through the local pygame path, the composed template plays a hand end to end, and a full CI run (Python checks, generation freshness, TypeScript checks, integration lane, browser journeys) is green on template version 2. The student docs and the contributor environment guide describe the convention — object-shaped observations, a simple `Discrete` action via helpers — and the specs and stage plans no longer describe the old observation shape as current behavior.
