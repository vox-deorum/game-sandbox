# Days at Three Branches Art Archive

Days at Three Branches is no longer part of Game Sandbox. This directory preserves its visual work as reference material without retaining runtime code.

- `source-art/` contains the 66 high-resolution originals.
- `runtime-assets/` contains the 65 optimized images used by the renderer.
- `thumbnail.png` is the environment card image.
- `hearthside-ink-approval.png` is the approved style reference.

Nothing in this directory is loaded by the application or included in an environment package.
